## How every block works (no re-reading)
1. **5 min warm-up:** read the topic's 60-second summary or one-page summary.
2. **Closed book:** write the answers or the sheet on paper *before* you look.
3. **Check:** correct in a different colour. Every mistake goes into the mistake list as one line:
   - 🟦 MDD: the ❌ list at the bottom of this file
   - 🟧 ML: `ML/exam-like/mistake-log.md`

**Bad-day minimum:** if today is a heavy day, do **one 25-min block**, the 🟦 one until 16 Dec. Small and done beats big and skipped. A missed day is not a failure; the plan already has room for it.

- Fewer than 6 blocks in a week → use the drop list below. Don't try to catch up everything.

## If it goes wrong
- **Missed 1 day:** before 16 Dec, the missed 🟦 block replaces the next day's 🟧 block. Missed 🟧 blocks are simply dropped from the list below.
- **Missed 3+ days:** drop in this order:
  1. ML classifier details (Mon 30 Nov)
  2. ML ERM 2nd time (Sun 6 Dec)
  3. MDD L9 paper → read only its 60-second summary
  4. ML Bayes 2nd time (Wed 2 Dec)
  5. MDD L6 → only its self-test page
- **Never drop:**
  - MDD: OCL Sheets 1–5, ATL Sheet 6, Sheets 7–8, both MDD mocks
  - ML: T1, SVD, EM, kernels, HPO, both ML mocks

## In both exams
1. Start with what you know cold.
2. Write *something* for every sub-task.
3. Stuck for more than 2 min → skip it and come back.
4. Respect the length hints ("1 sentence", "result suffices").
5. For ML, name the rule you use (sum rule, product rule, Bayes' theorem).
